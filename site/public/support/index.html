Support

BrowserForge is a small project, so support is direct: email us, or open an issue on GitHub where the fix can be tracked in public.

Email

support@browserforge.dev for anything involving a purchase, a licence key, a refund, or something you would rather not post publicly. Please include the extension name, browser and version. Security reports are welcome at the same address; please do not file them as public issues.

GitHub issues

Bugs and feature requests are tracked at github.com/shantanuojha/browserforge/issues. Search first; if nothing matches, open a new issue for the extension concerned:

  • Report an Arbor issue
  • Report a Reroute issue
  • Report a CookieSweep issue

For Arbor, attach the output of the Recovery screen if the problem involves your tree. For Reroute, include the rule and a URL that reproduces it. For CookieSweep, include the relevant lines from the activity log.

Frequently asked questions

Are these extensions Manifest V3? Will they keep working?
Yes. All three are built on Manifest V3 from the start, using the APIs Chrome, Edge and Firefox support today (declarativeNetRequest, side panel, service-worker background). They are not ports of retired MV2 extensions, so there is no deadline hanging over them.
Why does an extension need access to all sites?
Reroute and CookieSweep ask for host access to all sites because the browser APIs they rely on require it: a redirect rule can target any site you choose, and the cookie and site-data APIs only operate on sites the extension has access to. Neither extension reads page content or injects scripts. Arbor needs no host access at all. Every permission, with its reason, is listed on each product page (Arbor, Reroute, CookieSweep), and the source is public so you can check.
The code is open source. Why is there a Pro tier?
Because a tab manager that promises never to lose your tabs has to be maintained for years, and a one-time payment from the people who want the extras is how that gets funded without ads, telemetry or selling data. The free tiers are complete products, the Pro features are conveniences (automated backups, sync, power keys), and the code for all of it is MIT licensed. If you would rather build it yourself with the Pro features enabled, the licence lets you.
Is my data safe? Does anything leave my computer?
Your tabs, rules, lists and logs are stored in your browser and never sent to us. There is no analytics or telemetry. The only network calls are the licence check for Arbor Pro and Reroute Pro (to Lemon Squeezy, sending the key and an instance name) and, if you enable it, Arbor's backup to your own Google Drive. CookieSweep makes no network calls at all. The privacy policy spells this out per extension.
How do refunds work?
Email support@browserforge.dev with your order number within 14 days of purchase, or use the link in your Lemon Squeezy receipt. Lemon Squeezy, the merchant of record, refunds the original payment method and the key is deactivated. No reason required. Details are in the terms.
