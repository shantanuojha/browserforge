Reroute

Redirect and rewrite URLs by rule, and strip tracking parameters automatically. Reroute does one job: change a URL before the page loads, exactly the way you told it to.

Why Reroute

Manifest V3 retired a generation of URL tools. Redirector, which many people relied on for custom redirects, stopped working, and the extensions that stepped in each miss something: transforms, redirects inside single-page apps, or a faithful import of existing rules. ClearURLs, the standard tracking-parameter stripper, no longer supports Chrome.

Both jobs are the same job: rewrite this URL according to a rule. Reroute does that with the browser's built-in rule engine wherever possible, falls back to a small in-extension engine only when a rule needs a transform the browser cannot express, and never fetches rules or code from the network.

Features

  • Wildcard or regular-expression rules with $1 to $9 capture groups, exclude patterns, and a choice of resource types.
  • Transforms on captured text: URL-decode, URL-encode, Base64 decode and encode, lower and upper case.
  • Redirects that browser rules cannot express, including single-page-app URL changes (for example YouTube Shorts to the normal watch page), are handled by a fallback engine with loop protection.
  • Rule editor with a live tester: paste a URL and see which rule fires and what comes out.
  • Tracking-parameter cleaner built from the ClearURLs catalog. The catalog is compiled into the extension at build time, never downloaded at runtime.
  • Per-site allowlist for the cleaner, and a "Copy clean link" entry in the context menu.
  • A "what fired recently" log so you can see why a page was redirected.
  • Popup: turn Reroute on or off for the current site, see how many rules are active.
  • Import Redirector JSON and ClearURLs allowlists; export your rules as JSON.
  • Runs in Chrome, Edge and Firefox on Manifest V3.

Switching from Redirector or ClearURLs

Reroute imports the files those extensions export:

  • Redirector JSON exports. Include and exclude patterns, wildcard and regex types, the redirect target, process-matches options and the applies-to list are all mapped onto Reroute rules.
  • ClearURLs allowlist exports, which become per-site exceptions for the tracking-parameter cleaner.

The tracking-parameter catalog is derived from the ClearURLs rules (LGPL-3.0); attribution ships inside the extension. Reroute is an independent project and is not affiliated with or endorsed by Redirector or ClearURLs.

Permissions

Reroute asks for exactly the permissions below, declared in its manifest source. It never reads page content.

declarativeNetRequest
Hand your redirect rules and the tracking-parameter cleaner to the browser's own rule engine, which rewrites URLs without the extension seeing your traffic.
declarativeNetRequestFeedback
Show which rules matched in the "what fired recently" log and the rule tester.
webNavigation
Notice navigations and single-page-app URL changes so rules with transforms, which the browser engine cannot run, can be applied.
tabs
Update a tab's URL when one of those fallback rules matches.
storage
Save your rules, allowlist and settings locally (and, for Pro sync, in your browser account).
contextMenus
Add the "Copy clean link" item to the right-click menu.
Host access to all sites (<all_urls>)
A redirect rule can target any site you choose, and the browser requires host access to the site being redirected. Reroute uses it only to apply your rules; no page content is read or sent anywhere.

Privacy

Rules and logs stay on your device. Reroute has no analytics or telemetry and makes no network calls in the free tier. With Pro, the licence key is checked against api.lemonsqueezy.com. Details in the privacy policy.
